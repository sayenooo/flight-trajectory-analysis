# Data

This directory is intentionally kept free of OpenSky datasets in GitHub.

Store local raw and processed data here, for example:

```text
data/
├── raw/
├── interim/
└── processed/
```

Do not commit large, restricted, credential-bearing, or access-controlled datasets.

- Route: ZRH/LSZH → GVA/LSGG
- Preferred period: 2025-01-01 to 2025-12-31
