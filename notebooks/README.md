# Notebooks

Notebook sequence for the trajectory analysis project:

1. `01_dlh713_trajectory_preprocessing.ipynb` — readable preprocessing workflow for the current DLH713 dataset.
2. `02_trajectory_visualization.ipynb` — trajectory maps and visual inspection.
3. `03_feature_engineering.ipynb` — trajectory-level features for analysis.
4. `04_dimensionality_reduction.ipynb` — lower-dimensional feature representation.
5. `05_clustering_analysis.ipynb` — clustering and anomaly analysis.

Reusable data-processing logic is stored in `src/` so that the same steps can be run from notebooks or from the command line.
