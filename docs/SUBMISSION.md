# Submission checklist

The assignment requires a 15-minute presentation and simulation code. The deadline is Monday, October 12, 2026, with no late submissions. One student submits for the whole team, and individual peer assessments are separate.

Completed components: real one-direction flight data, documented preprocessing, HDBSCAN clustering, 15 parameter settings, real representative flights, inspection of three persistent candidate trajectories, references and AI disclosure.

Before submission:

1. Add confirmed names and student IDs to the presentation.
2. Confirm each member's actual contribution and AI-tool use. Do not invent individual authorship.
3. Divide the speaking sections and rehearse with `presentation/SPEAKER_NOTES.md`.
4. Open the PPTX in the software used to present, especially after importing into Canva or Google Slides.
5. Have a team member run `python run_pipeline.py` in a clean checkout and understand each stage. Existing student runs and the cleanup verification support the current results, but presentation readiness requires a team rehearsal.
6. Submit the presentation and repository/code. If offline data are required, include `data/lhr_fra_prepared/` in the submission archive.

The project uses a library HDBSCAN implementation. The optional from-scratch bonus is not claimed. Operational causes for the geometric candidates remain unverified.
